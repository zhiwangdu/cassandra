# Cassandra Source Research Knowledge Base

本目录用于沉淀当前 Cassandra 源码仓库的可复用技术知识库。目标不是总结单篇架构文，而是持续生成可以支撑开发、运维、故障排查、性能优化和二次开发的模块化研究资料。

## 当前仓库基线

- 分支：`cassandra-5.0`
- 当前提交：`659c0a526ba382af68be3cd07e56b42018fb73db`
- 版本线索：`base.version=5.0.9`，定义在 `build.xml:36`
- Java 支持线索：`java.supported=11,17`，定义在 `build.xml:48`
- 研究入口：`src/java/org/apache/cassandra`
- 测试入口：`test/unit`、`test/distributed`、`test/long`

## 文档组织

- `module-*.md`：按模块沉淀设计目标、核心类、接口、数据结构、生命周期、配置、metrics、日志、运维、性能与故障。
- `flow-*.md`：关键链路的文字版调用图，要求能从入口走到本地/跨节点执行点。
- `notes/*.md`：源码地图、阅读约定、跨模块索引和后续问题。
- `tools/*.py`：仅依赖源码和研究文档的 drift check / 辅助校验脚本。
